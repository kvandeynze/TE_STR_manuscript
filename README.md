# Transposable element-associated short tandem repeats reveal architecture-specific drivers of instability and disease 

This is the repository for scripts used to conduct QC and analysis for the manuscript. It is organized as follows

1. QC_scripts
This directory contains the scripts used to process the tdb databases constructed from trgt vcfs from 100 HPRC samples. 

1. feature_generation_scripts
Scripts for generating STR regions as well as assignments to all metadata fields including TE association, position relative to Alu consensus sequences, genomic region annotation, disease assciation, and TE subregion assignments

1. figure_notebooks
All jupyter notebooks used for figure generation for the manuscript.
